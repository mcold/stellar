Async materialized view (manual refresh)
CREATE MATERIALIZED VIEW mv_async_manual
DISTRIBUTED BY HASH(order_date) BUCKETS 10
REFRESH MANUAL
AS SELECT 
    order_date,
    SUM(amount) as daily_sales,
    COUNT(*) as order_count
FROM orders
GROUP BY order_date;
Async materialized view (auto refresh)
CREATE MATERIALIZED VIEW mv_async_auto
DISTRIBUTED BY HASH(order_date) BUCKETS 10
REFRESH ASYNC EVERY (INTERVAL 1 HOUR)
AS SELECT 
    order_date,
    SUM(amount) as daily_sales
FROM orders
GROUP BY order_date;
Sync materialized view (ROLLUP, refreshed on load)
CREATE MATERIALIZED VIEW mv_sync_rollup
AS SELECT 
    customer_id,
    order_date,
    SUM(amount) as total_amount,
    COUNT(*) as order_count
FROM orders
GROUP BY customer_id, order_date;

Common properties
  • session.enable_profile - Enable profile (true/false)
  • session.enable_spill - Enable spilling intermediate results to disk (true/false)
  • session.spill_mode - Spill mode (auto/force)
  • mv_rewrite_staleness_second - Query rewrite staleness time (seconds)

  • partition_refresh_number - Partition refresh count

Generated SQL: ALTER MATERIALIZED VIEW ... SET ("{{ editPropertyKey }}" = "{{ editPropertyValue }}")

Supported ALTER clauses:
  • RENAME new_name - Rename
  • REFRESH MANUAL or REFRESH ASYNC EVERY(...) - Change refresh strategy
  • ACTIVE or INACTIVE - Change status
  • SET ("key" = "value") - Change properties
  • SWAP WITH other_mv_name - Atomic swap
